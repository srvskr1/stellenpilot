**Windows:** download **Stellenpilot-Setup-VERSION.exe** and run it. No Python needed. Windows may warn that the app is from an unknown publisher (it is not code signed yet): click **More info**, then **Run anyway**.

**Mac (Apple chip, M1 or newer):** download **Stellenpilot-VERSION-mac.dmg**, open it and drag Stellenpilot into Applications. The app is not signed by Apple yet, so the first start needs one extra step: [how to open it](https://github.com/srvskr1/stellenpilot/blob/main/docs/mac.md).

**Python users** (any system): `pip install -U stellenpilot`
