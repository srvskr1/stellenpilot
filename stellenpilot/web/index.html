      How to get your free Adzuna keys (about 3 minutes)
              
        
                
      1. Open developer.adzuna.com and register. It is free; any website field can be your GitHub or LinkedIn profile.
        2. 
                
      2. Confirm the email Adzuna sends you, then log in.
        3. 
                
      3. On your Adzuna developer dashboard you see two values: Application ID (short, 8 characters) and Application Key (long, 32 characters).
        4. 
                
      4. Copy the Application ID into App ID below and the Application Key into App key, then press Save settings.
        5. 
              
      
              
      The free plan allows 250 searches a day; Stellenpilot uses at most 20 per run. Never share these keys or paste them in chats.
      
            
      
            
      
            
      
          
      
            
      How to get your free TheirStack key (about 2 minutes)
              
        
                
      1. Open theirstack.com and sign up for free (Google sign in works).
        2. 
                
      2. Open your account settings and find the API key section.
        3. 
                
      3. Copy the key (a long text) into API key below and press Save settings.
        4. 
              
      
              
      The free plan has 200 credits a month, one credit per job found. Stellenpilot asks for 6 jobs a run, which lasts a month of daily searches. Keys are personal, so never share yours.
      
            
      
            
      
          
      
          
      
          
      
          
      Saved keys are not shown again. Leave a key box empty to keep the saved one.
